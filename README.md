# Assetly

Marketing website for Assetly, a B2B operating-lease structuring company. The site explains the lease-vs-loan-vs-purchase proposition, establishes brand credibility, and converts visitor interest into a Gmail-drafted enquiry.

Two public pages (`/`, `/about`) and one Firebase-authenticated internal panel (`/admin`) for managing the homepage's "Trusted By" logo strip. Built with Next.js (App Router), React, and TypeScript.
